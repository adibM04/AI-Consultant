# Support

This is a small open-source project, not a product with a support contract. There is no
SLA, no paid tier, and nobody on call.

## Where to go

| You want | Go here |
|---|---|
| To install it, or see the commands | [README](README.md) |
| To understand what it cannot do | [docs/limits.md](docs/limits.md) |
| A usage question, or help reading a report | [Q&A discussions](https://github.com/adibM04/AI-Consultant/discussions/categories/q-a) |
| To suggest something that should exist | [Ideas discussions](https://github.com/adibM04/AI-Consultant/discussions/categories/ideas) |
| To see what is planned | [Roadmap](ROADMAP.md) |
| A check that is missing | Issue template: **Propose a checklist item** |
| A finding that is wrong in either direction | Issue template: **Wrong audit result** |
| The tool crashed or installed badly | Issue template: **Something is broken** |
| A security problem in this project | [SECURITY.md](SECURITY.md) — never a public issue |

## Before you open an issue

- Read the report's own "What I could not verify" section. Many questions are already
  answered there, and a report that says `unknown` is working as designed.
- Search the existing issues. Duplicates are closed, not answered faster.
- Redact secrets, customer data and repository contents you do not want public.

## What you can expect

A best-effort reply when a maintainer has time. A clear "no" is more likely than a
promise, and a minimal reproduction is the fastest route to a fix. If you need a
guarantee about your production system, this project is not a substitute for an
engineer, a penetration test, or a lawyer.
